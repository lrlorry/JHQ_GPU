\section{Adaptive Hierarchical Refinement}
\label{sec:method2}
\subsection{Output-stability criterion}
For a fixed index, routing configuration and $k$, we calibrate a workload-level
budget on $S$ sampled queries $Q_s$ and reuse it for subsequent batches. Let
$R_{\max}(q)$ and $R_\alpha(q)$ be top-$k$ ID sets at a generous reference
budget $\alpha_{\max}$ and a candidate $\alpha$. Define
\begin{equation}
D(\alpha)=\sum_{q\in Q_s}\bigl[k-|R_\alpha(q)\cap R_{\max}(q)|\bigr].
\label{eq:disagree}
\end{equation}
Acceptance requires $D(\alpha)\le\epsilon$, where $\epsilon$ is a non-negative integer
counting allowed disagreeing slots over the whole sample. It ignores ID order,
and fixed $\epsilon$ becomes stricter as $S$ grows. Agreement neither certifies
ground-truth recall nor detects improvements beyond $\alpha_{\max}$.

\subsection{Search rule and its assumptions}
\label{sec:mono}
For descending grid $A[0],\ldots,A[L-1]$ with $A[0]=\alpha_{\max}$, compute
the reference once and initialise $l=0$, $h=L-1$. While $l<h$, test
$j=\lceil(l+h)/2\rceil$. If $D(A[j])\le\epsilon$, set $l=j$; otherwise set
$h=j-1$. Return $A[l]$, an observed acceptable point, with $A[0]$ as fallback.
The held-out experiment uses $A=(200,100,64,32,16,8,4,2)$ and $\epsilon=1$.

\begin{proposition}[Monotonicity under exact primary selection]
\label{prop:mono}
With exact top-$c_k$ primary selection, non-decreasing $c_k$, fixed refined
scores and a deterministic total tie rule,
$D(\alpha_1)\ge D(\alpha_2)$ for $\alpha_1\le\alpha_2\le\alpha_{\max}$.
\end{proposition}
\begin{proof}
The survivor sets nest: $S_{\alpha_1}\subseteq S_{\alpha_2}\subseteq
S_{\alpha_{\max}}$. Any reference top-$k$ item present in $S_\alpha$ also
belongs to its refined top-$k$, because fewer than $k$ items of the larger set
precede it under the fixed ordering. Hence
$R_\alpha\cap R_{\max}=S_\alpha\cap R_{\max}$, whose size cannot decrease
as $\alpha$ increases. Summing proves the claim. \qed
\end{proof}

The production selector retains only $\texttt{K\_LOCAL}=4$ candidates per
thread before merging, so it need not satisfy the proposition's premise.
Bisection therefore does not guarantee the grid's smallest acceptable budget.
Section~\ref{sec:rq2} compares it directly with whole-grid enumeration.
Acceptance remains relative to the sampled criterion. Section~\ref{sec:related}
positions this label-free rule against existing ANN tuning methods.

\subsection{Calibration economics}
Let $T_{\mathrm{cal}}$ be calibration time and $T_{\mathrm{fixed}}$ and
$T_{\mathrm{rule}}$ be batch times with fixed and selected budgets. For $B$
subsequent batches, adaptive search costs
$T_{\mathrm{cal}}+BT_{\mathrm{rule}}$ against $BT_{\mathrm{fixed}}$, so
break-even is
$B^{*}=T_{\mathrm{cal}}/(T_{\mathrm{fixed}}-T_{\mathrm{rule}})$ and
calibration never repays once $T_{\mathrm{rule}}\ge T_{\mathrm{fixed}}$. Reuse assumes stable queries, index, routing and $k$. Recalibrating every
$H$ batches adds $T_{\mathrm{cal}}/H$ per batch; drift detection is outside the
measured scope.
