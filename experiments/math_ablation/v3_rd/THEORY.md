# V3 RD-JHQ：理论与前提

## 1. JHQ 的残差 [源码]

- 残差 r = y − ŷ_P，每个 8 维子空间一个 256 电平的标量码本，由该子空间 8 个坐标的残差合在一起，用 1-D Lloyd 训练；
- 每维 8 bit，每向量 d 字节，另加一个 float（corr = 2⟨ŷ, r̂⟩）；
- 精排距离 D_H = ‖q′ − ŷ_P − r̂‖²。

## 2. 码率分配理论 [证明]

**高斯情形：** 独立高斯分量 y_j ~ N(0, λ_j)，在平方误差下的率失真函数是反向注水：

  D(θ) = Σ_j min(θ, λ_j)，b_j = [½ log₂(λ_j / θ)]₊，Σ_j b_j = 总码率。

**高码率标量量化：** D_j(b) ≈ κ λ_j 2^{−2b}。在 Σb_j 固定、b_j 不受整数和上下限约束时，最优分配满足 λ_j 2^{−2b_j} 相等，总失真比均匀分配低一个因子：

  D_最优 / D_均匀 = GM(λ) / AM(λ)，

即几何平均与算术平均之比。这是 `rd.py stats` 中 `gaussian_waterfilling_gain_bound` 的来源，它给出了**收益上限**。

**有限码率下的修正：** 每维 6–10 bit 的 Lloyd 标量量化器并不严格服从 2^{−2b}，所以另外实测每个子空间在 b = 6…10 时的失真 D_m(b)（在留出样本上测），再用贪心做整数分配。对凸的 D_m，贪心是最优的。

## 3. JL 旋转会把方差拉平

**理论：** 对随机正交旋转 Π，每个旋转后坐标的方差的期望都等于 tr(Σ)/d。离散程度由谱决定：协方差越集中（有效秩越低），旋转后各坐标方差的离散越大，但它随 d 增大而减小。

**实测**（rank-optimal 研究 prep，旋转后 y 的坐标标准差变异系数）：arxiv 0.078、vogue 0.128、openai3 0.042。

**推论：**
- 残差方差很可能更均匀，GM/AM 接近 1，注水的上限收益只有百分之一量级；
- 按子空间分配（8 维取平均）比按维分配更均匀。
- 这一上限必须先算出来（brief V3-A）；上限本身就很小时，结论多半是 NO-GO。

## 4. 查询加权

精排误差 D_H − D ≈ 2⟨q′ − y, r − r̂⟩ + ‖r − r̂‖²，其方差约为 Σ_j E[(q′_j − y_j)²]·MSE_j。所以“查询加权”的分配应最小化 Σ_m w_m D_m(b_m)：
- w_m 为子空间 m 上 (q′ − y)² 在校准查询及其近候选上的均值；
- 只用校准集查询的候选，不读真值标签。

## 5. 公平性与实现要求

- **预算严格相等：** Σ_m 8·b_m = 8d，每向量仍是 d 字节，打包为真实的变位宽比特流（MSB 优先）；
- **重新训练与编码：** 每个子空间按 2^{b_m} 电平重新训练码本，重新编码；
- **正确性：** 解码后与编码逐位一致（`rd.py test` 与 build 中的往返检查）。

**GPU 代价：** 变位宽解码需要按位提取，并跨字节、跨 32 位字边界。均匀 8 bit 时，每个码就是一个字节，可以直接读。所以变位宽的精排更慢，只有离线质量收益明显时才值得做 GPU 原型。
