# V2 EVT-JHQ：理论与前提

## 1. 问题

**v65 的做法：** 路由选出 nprobe 个 list 后，扫描它们的全部 primary 码，取 primary 距离最小的 ck 个候选，用 D_H 精排。

**V2 想做的：** 在读一个 list 之前，判断它能否贡献比当前 top-ck 门限 τ 更好的候选；判断为不能的就整个跳过。“整个跳过”才有意义：读了码再决定等于没省。

**决策时可用的量（读 list 之前就有）：**
- τ：已扫描部分的第 ck 小 primary 距离；
- δ_ℓ = ‖q′ − c_ℓ‖²：路由时已经算过，免费；
- list 大小 n_ℓ：一次查表；
- list 的探查名次。

## 2. 极值模型 [证明] 及其前提

**i.i.d. 情形：** 若 list ℓ 中各候选的 primary 距离独立同分布，分布函数为 F_ℓ，则

  P(min_{x∈ℓ} D_P(x) < τ) = 1 − (1 − F_ℓ(τ))^{n_ℓ}。

由 Fisher–Tippett–Gnedenko 定理，规范化后的最小值在 n 大时趋于 GEV 分布（三种类型之一）。

**真实 ANN 候选不满足这个前提，原因有三：**
1. **不独立：** 同一 list 的成员共享位置，它们到查询的距离通过“查询–list 几何”强相关。
2. **不同分布：** F_ℓ 依赖查询相对 list 的位置，不能对所有 list 共用一个分布。
3. **n 不大：** list 平均 122–275 个成员，而关心的是下尾的极端分位数。

所以公式只能当作一个模型族，概率必须在真实查询上校准（brief 的要求）。

**`evt_sim.py` 比较四种风险模型（只用校准集拟合）：**

| 模型 | 形式 | 性质 |
|---|---|---|
| global | 按 u = τ − δ_ℓ 分箱的经验频率 | 固定的全局统计 |
| iid_evt | 1 − (1 − F(τ − δ_ℓ))^{n_ℓ}，F 为合并的 D_P − δ_ℓ 经验分布 | brief 公式的直接实现 |
| gev | 对 list 最小值偏移按 list 大小分档拟合 GEV | 报告 KS 拟合度 |
| logistic | 特征 (u, log n, 名次, δ_ℓ − δ_1) | 校准后的经验尾部风险 |

## 3. 剪枝能省多少：上限与对照

**上限（oracle）：** 只扫描那些“含有全扫描 primary top-ck 中至少一个候选”的 list。任何 list 级规则在不丢 top-ck 的前提下都不可能比它省得更多。

**对照（降 nprobe）：** 只扫描离查询最近的前 n′ 个 list。如果 EVT 规则在相同 recall 下扫描的候选不比降 nprobe 少，它就只是变相的降 nprobe（brief 第 3 节）。

**GPU 上的额外代价**（这一节是推导，不是实测）：
- 需要两阶段或多阶段扫描：先扫前 L1 个 list 得到 τ，再决定其余 list。v65 把一个查询的 list 分成 G 组并行扫描，阶段之间要同步，并行度下降。
- 跳过不规则的 list 会让 warp / CTA 的负载不均衡。
- 风险计算本身很便宜（每个 list 几次浮点运算）。

## 4. 与已有工作的关系（详见 NOVELTY_AUDIT.md）

- 按查询自适应地决定扫描哪些 list、何时停：Learned Adaptive Early Termination（Li 等，SIGMOD 2020）、DARTH（2025）、ConANN（VLDB 2025，保形风险控制给出 FNR 保证）。
- 用几何下界跳过整个 cluster：CLIP（2026，余弦定理下界）。
- 用极端顺序统计量的近似分布做剪枝：图索引上的概率路由（2024，最小值的正态近似）。

V2 至多是这些思路在 JHQ primary 距离上的一个组合，**不宣称 EVT 本身是新方法**。
