**openai3 的偏差：** 离线 fp32 旋转得到的 y 与论文索引编码时的 y 在 1e-6 量级上不同，形态上像编码路径用了较低精度的矩阵乘。这导致 9.3e-5 的主码位和 2.7% 的残差码落在边界另一侧；用导出的码重算 D_H 仍精确一致。这点差异对排序影响可以忽略（距离尺度约 0.5），第 2 轮用 `jhq_re` 在 recall 层面核对。

**残差码本重训：**
- 离线重训的残差码本与导出码本并不逐位相同：重新编码后的码字一致率为 84.5% / 97.3% / 90.5%（arxiv / vogue / openai3），所有子空间都跑满 2000 次迭代。
- 原因是 1-D Lloyd 在 2000 次内没有收敛，float32 与 float64 的运算差异把两条收敛轨迹带到了不同位置。仓库 CLAUDE.md 也记录过：训练不可复现，换 seed 时 91% 的残差码会变。
- 因此本研究的所有量化变体（包括 JHQ 的离线复现 `jhq_re`）都用**同一个**离线残差训练流程，与论文索引的比较看 recall 层面是否一致（第 2 轮报告）。

**改变量化规则会影响哪些模块：**
- **按维的规则（每维阈值和电平）：** 改编码器、LUT 表值（每维两个电平，16+16 分解仍可分离）、残差码本与残差码、corr。扫描 kernel 的结构不变。
- **按 list 的规则：** 每个（查询，list）需要一张表，扫描结构要改，见 5.6 节。

## 2. 现有 1-bit 筛选的最优性边界

### 2.1 E[X | s] = σ√(2/π)·s [证明]

设 X ~ N(0, σ²)，则

  E[X | X > 0] = ∫₀^∞ x·φ(x/σ)/σ dx / P(X > 0) = (σ/√(2π)) / (1/2) = σ√(2/π)。

由对称性，E[X | X < 0] = −σ√(2/π)。所以 E[X | s] = σ√(2/π)·s ≈ 0.7979σ·s。∎

JHQ 实际用的电平是 0.6745σ（|X| 的中位数），不是条件均值 0.7979σ。这不影响 primary 排序（见 2.2），只影响残差的分布。

### 2.2 JHQ 的 primary 排序 = 条件期望距离的排序 [证明]

**模型 M0：** 各坐标独立；E[y_j | s_j] = κ·s_j，且 κ 对所有 j 相同；E[y_j² | s_j] = τ² 与 s_j 无关（对称分布即满足）。则

  E[‖q′ − y‖² | s] = ‖q′‖² − 2κ⟨q′, s⟩ + dτ²，

它随 ⟨q′, s⟩ 严格递减。JHQ 的 D_P = ‖q′‖² + dc² − 2c⟨q′, s⟩ 对任意 c > 0 给出同样的顺序。

推论：
1. **c 不影响 primary 排序：** 无论取 0.6745σ 还是 0.7979σ，排序都一样。
2. **JHQ 的 primary 排序就是 M0 下距离 MMSE 估计的排序：** 它是“给定码，在平方损失下估计距离”的贝叶斯估计量的排序。∎

### 2.3 这不等于 Top-k recall 最优 [证明 + 数值]

**概率排序原则：** 要让 Top-T 中真近邻的期望个数最大，应按 π(x) = P(x ∈ NN_k(q) | s(x), q) 排序。这里简化地假设各候选独立。

只有当后验分布按均值随机有序时（例如位置族），按 E[D | s] 排序才等价于按 P(D < τ | s) 排序。M0 下不是这样：
- 对第 j 维，令 u = s_j·q_j（符号一致时为正）。|y_j| 服从半正态分布，于是
  - E[(q_j − y_j)² | s_j] = σ² − 2uσ√(2/π) + u²；
  - 方差在 u = +σ 时为 0.27σ⁴，在 u = −σ 时为 6.64σ⁴。
- 后验方差依赖于“在哪些维上一致”，因此均值相同的两个候选，P(D < τ) 可以不同。

所以 MMSE 排序原则上不是 recall 最优的。这是第 1 轮的理论动机。

## 3. 近邻似然比分数（第 1 轮）

### 3.1 推导 [证明]

设背景 H0：X ~ N(0, σ²I)；近邻 H1：p₁(x | q) ∝ p₀(x)·e^{−β‖x−q‖²}。配方可得：
- H1 是 N(μ₁, σ₁²I)，其中 σ₁² = σ²/(1 + 2βσ²)，μ₁ = 2βσ₁²·q。
- P(s_j = +1 | H1) = Φ(μ₁ⱼ/σ₁) = Φ(λq_j)，其中 λ = 2βσ/√(1 + 2βσ²)。
- 在 H0 下 P(s_j) = ½，所以 L_β(q, s) = Σ_j log[2Φ(s_j·λq_j)]。∎

### 3.2 仿射形式 [证明]

s_j 只取 ±1，所以对任意函数 f 都有 f(s) = (f(+1) + f(−1))/2 + s·(f(+1) − f(−1))/2。于是

  L_β = C(q) + Σ_j w_j(q)·s_j，

其中：
- w_j = ½·ψ(λq_j)；
- C(q) = ½·Σ_j [log 2Φ(λq_j) + log 2Φ(−λq_j)]，与候选无关。

JHQ 的权重是 w_j ∝ q_j；LLR 的权重 w_j = ½ψ(λq_j) 是关于 q_j 的奇、单调、非线性函数。

### 3.3 极限 [证明 + 数值]

- **小 β（λ → 0）：** ψ(t) = 4φ(0)·t + ((16φ(0)³ − 2φ(0))/3)·t³ + O(t⁵) ≈ 1.5958t + 0.0727t³。
  - 因此 w_j = 2φ(0)λq_j·(1 + O(λ²q_j²))，λ → 0 时排序与 JHQ 完全相同。
  - 相对偏差在 λq = 1 时为 4.5%，λq = 2 时为 17.8%（数值见 §1 输出）。
- **大 β（λ → √(2β) → ∞）：** ψ(t) = sign(t)·(t²/2 + log(|t|√(2π)) + o(1))。t = 4 时误差已降到 0.5%。
  - 因此 w_j ≈ ¼λ²·q_j|q_j|，极限下按 Σ_j q_j|q_j|·s_j 排序，即平方加权。
- **高维：** JL 之后 q′_j ≈ N(0, ‖q‖²/d)，λq′_j 的量级是 λσ。
  - 只有当 λσ = O(1)，即 2βσ² = O(1) 时，重加权才有实质影响。这要求近邻模型集中到单个坐标的尺度。
  - 实测的近邻去中心相关为 0.63 / 0.66 / 0.53（arxiv / vogue / openai3），对应 κ = ρ/√(1−ρ²) ≈ 0.6–0.9，处在非线性区的边缘。

### 3.4 它只是重加权吗？是的 [证明]

独立二值特征的任何对数似然比都关于 s 仿射。LLR 不能带来码以外的信息，只能换一个 s 的线性泛函来排序。

**纯重加权在模型内的上限：** 用 h(q) 加权，区分相关水平 ρ₁ 与 ρ₀ 的信噪比为

  SNR(h) = d·(E[hg])² / E[h²v]，

其中 g = 2(Φ(κ₁q) − Φ(κ₀q))，v = 4(Φ₁(1−Φ₁) + Φ₀(1−Φ₀))。由 Cauchy–Schwarz，最大值在 h* = g/v 处取得：

  SNR*/SNR_JHQ = E[g²/v]·E[q²v] / (E[qg])²。

数值（§2 输出）：
- 局部最优 h* 相对 JHQ 的 SNR 只有 **×1.004–1.015**，h* 与 q 的夹角余弦为 0.957–0.996；
- 论文模型的 LLR 权重（λ = κ₁）为 ×0.958–1.009，**在部分相关水平下反而比 JHQ 差**。

**预言：** 仅靠改打分，排序信噪比最多提高约 1.5%，T 的减少应远小于 10%。这是第 1 轮的否定标准依据。

### 3.5 偏置感知与局部最优（LMP）变体 [证明]

- **LLR-bias：** H0 = Π_j N(μ_j, σ_j²)（按维实测），H1 = H0·e^{−β‖y−q′‖²}。
  - 则 σ₁ⱼ² = σ_j²/(1 + 2βσ_j²)，μ₁ⱼ = σ₁ⱼ²(μ_j/σ_j² + 2βq′_j)。
  - 权重为 w_j = ½[ψ(μ₁ⱼ/σ₁ⱼ) − ψ(μ_j/σ_j)]：对 bit 几乎恒定的维（|μ_j|/σ_j 大）自动降权。
- **LMP（检验相关水平 κ 的局部最优统计量）：** w_j ∝ q_j·φ(κq_j)/(Φ(κq_j)·Φ(−κq_j))；κ → 0 时还原为 JHQ。

## 4. 误排序界（Phase 3）

### 4.1 定理 [证明]

**设定：**
- 查询 q 固定；
- 正例 X⁺ ~ P₁ = Π_j P₁ⱼ，负例 X⁻ ~ P₀ = Π_j P₀ⱼ，两者相互独立，并且各坐标的 bit 在 P₀ 和 P₁ 下都独立；
- p₁ⱼ = P₁(b_j = 1)，p₀ⱼ = P₀(b_j = 1)；
- 打分是精确的 LLR：ℓ(b) = Σ_j ℓ_j(b_j)，ℓ_j(b) = log(P₁ⱼ(b)/P₀ⱼ(b))。

则

  P_misrank := P(ℓ(b⁺) ≤ ℓ(b⁻)) ≤ Π_j ρ_j²，其中 ρ_j = √(p₁ⱼp₀ⱼ) + √((1−p₁ⱼ)(1−p₀ⱼ))。

**证明：** 对任意 t ≥ 0，由 Markov 不等式和独立性，

  P(ℓ(b⁻) − ℓ(b⁺) ≥ 0) ≤ E[e^{t(ℓ(b⁻) − ℓ(b⁺))}] = Π_j E_{P₀}[e^{tℓ_j}]·E_{P₁}[e^{−tℓ_j}]。

取 t = ½：E_{P₀}[(P₁/P₀)^{1/2}] = Σ_b √(P₁(b)P₀(b)) = ρ_j，E_{P₁}[(P₀/P₁)^{1/2}] = ρ_j。∎

**补充说明：**
- **t = ½ 是最优的：** 令 A(t) = Σ_b P₀^{1−t}P₁^t，它是 log-凸的。f(t) = A(t)·A(1−t) 关于 ½ 对称且 log-凸，所以在 t = ½ 取最小。
- **并列：** “≤” 包含平局，平局一律算作误排序。
- **新颖性：** 这是经典的 Chernoff/Bhattacharyya 技术（两类 Bayes 误差界的配对版本）。本工作只是把它用于 1-bit 筛选，**不宣称是新定理**，见 NOVELTY_AUDIT.md。

### 4.2 非 LLR 打分（例如 JHQ）的合法界 [证明]

对 S = Σ_j w_j s_j，同样的 Chernoff 论证给出

  P(S⁺ ≤ S⁻) ≤ min_{t≥0} Π_j [(p₀ⱼe^{2tw_j} + 1 − p₀ⱼ)·(p₁ⱼe^{−2tw_j} + 1 − p₁ⱼ)]·e^{0}。

推导时 s_j⁻ − s_j⁺ ∈ {−2, 0, 2}，按各自的概率展开即可。这个界逐查询可数值计算。

### 4.3 对真实数据的适用性

- **(a) 正负例独立：** 合理。
- **(b) 坐标独立：** 不成立（2.4 节）。所以该界对真实数据**不是保证**，只是“独立化模型”下的预测值。
- **(c)、(d)：** 需要逐查询估计 p₁、p₀，可以用 GT 近邻的 bit 频率和背景候选的 bit 频率。

**不依赖任何独立性的合法替代：** 对经验的正负对差 Δ = S⁺ − S⁻，若 E[Δ] > 0，则 Cantelli 不等式给出 P(Δ ≤ 0) ≤ Var Δ / (Var Δ + (E Δ)²)。它只要求二阶矩，但描述的是经验分布本身，并且较松。

`RANK_ERROR_ANALYSIS.csv` 对照经验误排序率、模型界和 Cantelli 界。

### 4.4 配对误排序界不等于 Top-k Recall 保证

对单个正例，P(rank(x⁺) > T) ≤ E[#{x⁻ : S(x⁻) ≥ S(x⁺)}]/T ≤ n·p_mis/T（Markov）。这只给出一个很松的 Top-T 漏检上界：例如 n = 4.7 万、p_mis = 1e-3 时，T = 1000 的上界是 4.7%。

配对误排序率本身**不是** recall 保证，两者不能混淆。

## 5. 排序最优阈值（第 2 轮）

### 5.1 目标

b_j = 1[y_j > t_j]。最小化 E_q Σ_j log ρ_j(q, t_j)，即误排序界的对数在查询分布上的平均。这个目标关于 j 可分，因此是逐维的一维优化。

### 5.2 对称位置模型下，最优阈值是分布中心 [证明 + 数值]

**模型：**
- 背景 y ~ N(m, 1)；
- 查询 q 关于 m 对称分布（查询与库同分布）；
- 近邻 y | q ~ N(m + ρ(q − m), 1 − ρ²)。

**论证：**
- 作反射 y → 2m − y、q → 2m − q。它把 p₀(m+u) 映为 1 − p₀(m−u)，把 p₁(m+u | q) 映为 1 − p₁(m−u | 2m−q)。
- ρ 在同时交换 p ↔ 1−p 时不变，所以 g(m+u) = g(m−u)，t = m 是驻点。
- 数值（§3 输出）表明它是全局最小点：m = 0, 0.5, 1，ρ = 0.8, 0.9 时，argmin t = m，精度达到 1e-5。
- 在零阈值处，每坐标的误排序指数 −2g 只剩最优值的 88%（m = 0.5σ）和 60–62%（m = 1σ）。

**结论：** 零阈值是排序最优的，当且仅当旋转后的数据在该维以 0 为中心（并且对称）。这正是论文 Lemma 2 的隐含假设。

### 5.3 偏置阈值的信息损失 [数值]

阈值偏离中心 a 个标准差时，一个 bit 对位置偏移的 Fisher 信息为 I(a) = φ(a)²/(Φ(a)Φ(−a))，相对 I(0) 的比值见 §4 输出：
- a = 0.25 时 0.978，a = 0.5 时 0.913；
- a = 1.0 时 0.689，a = 1.5 时 0.423，a = 2.0 时 0.206。

按各数据集 |μ_j|/σ_j 的均值估计（1.22 / 0.43 / 0.23），JHQ 的 bit 分别只保留约 57% / 93% / 98% 的信息。这预言第 2 轮的收益应按 arxiv ≫ vogue > openai3 排序。

### 5.4 Lloyd–Max（重建最优）与排序最优阈值的关系

- 对称单峰分布：两者都等于中心，重合。
- 偏斜分布：Lloyd–Max 的阈值是两侧条件均值的中点，排序最优（Bhattacharyya）的阈值是中位数，两者不同。
- 实测边缘分布接近对称（偏度约 0.08），所以预计 `median`、`mean`、`lloydmax` 三者几乎相同。**这正是第 2 轮的对照点。**

### 5.5 给定阈值时的最优重建值

两侧取条件均值，即 Lloyd–Max 的质心条件：hi_j = E[y_j | y_j > t_j]，lo_j = E[y_j | y_j ≤ t_j]。

完整的条件期望距离是

  E[‖q−y‖² | b] = Σ_j (q_j² − 2q_j·E[y_j | b_j] + E[y_j² | b_j])。

它比 LUT 形式 ‖q − ℓ‖² 多一项按维、按侧的方差差，仍然逐维可分，可以并入表值。所以 16+16 分解与扫描结构都不变。

### 5.6 IVF 条件阈值

对 list ℓ 的候选，背景是该 list 的成员分布。同样的论证给出 t_{ℓj} = 该 list 在第 j 维的中心，这就是相对 IVF 质心编码残差（IVFADC / RaBitQ 的做法）。

**代价：**
- 每个（查询，list）需要一张表：表值 = Σ_{j∈m} (q′_j − ℓ_{ℓj}(b))²，可以按 list 现场构建；
- 或每向量存一个与 list 质心相关的标量，但这违反本研究的 bit 预算约束。

## 6. 编码预算

| 方案 | 每向量 | 全局 | IVF 相关元数据 | 查询端额外工作 |
|---|---|---|---|---|
| JHQ | d bit 主码 + 8d bit 残差 + 1 个 float（corr） | Π（d²）、σ、残差码本（M×256） | 质心 nlist×d（路由用） | — |
| 第 1 轮（LLR 打分） | 不变 | 不变（LLR-bias 另加 2d 个 float） | 不变 | 每维一次非线性函数 |
| 第 2 轮（按维阈值） | 不变 | 另加 3d 个 float（t、lo、hi） | 不变 | LUT 用每维电平 |
| 按 list 阈值 | 不变 | — | nlist×d×3 个 float（或 fp16） | 每个（查询，list）建一张表 |

所有方案的每向量 bit 数严格等于 JHQ：1 + 8 bit/维 + 1 个 float。
