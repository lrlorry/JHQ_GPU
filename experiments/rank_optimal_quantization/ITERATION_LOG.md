# 迭代日志（Research Loop）

每一轮按 Hypothesis → Derivation → Minimal Implementation → Experiment → Diagnose → Redesign → Update 记录。

“预注册”的部分写在看到该轮结果**之前**，并随对应 commit 一起提交；结果与诊断在实验结束后追加。

**全局规则：**
- **数据划分：** 校准 400 / 验证 200 / 测试 400 条查询。参数在校准集选，匹配预算在验证集读，测试集只在最终确认时使用一次。
- **基线：** JHQ 即论文索引本身（v65 的候选、FP64 D_prim 与 D_H）。
- **目标 recall：** 同一划分上 JHQ 在 T = ck 处的 recall。
- **T_min：** 网格上 recall 达到目标的最小 T。

## 第 1 轮：近邻似然比打分（不改编码）

**预注册（2026-10-13，结果前）**

- **假设 H1：** 在同一套 JHQ 1-bit 码上，用近邻似然比（LLR）w_j = ½ψ(λq'_j) 代替 JHQ 的线性权重 q'_j，真近邻在 primary 排序中的位置会更靠前，达到目标 recall 所需的 T 更小。另测两个变体：
  - 偏置感知的背景模型（LLR-bias）；
  - 区分相关水平的局部最优权重（LMP）。
- **理论动机：**
  - 概率排序原则：最优排序应按“是近邻的后验概率”，而 JHQ 的 primary 距离只是条件期望距离（MMSE）的排序。
  - 在 M0 模型下，后验方差依赖每一维的符号一致模式（THEORY.md 2.3），因此 MMSE 排序不一定是 recall 最优的。
- **与 JHQ 的本质区别：**
  - 只改变排序用的线性泛函（每维权重），编码、码本、残差都不变；
  - GPU 上只是 LUT 的表值换成 w_j，结构不变。
- **预期：** 模型内纯重加权的 SNR 上限增益只有百分之几（THEORY.md 3.4，`theory_numerics.py` §2），所以预计 T 的减少 < 10%。
- **成本：** 每向量 0 bit。查询端每维多算一次非线性函数。
- **否定标准：** 校准集选出的参数下，三个数据集在验证集上的 T_min 都减少不到 10%，则判定 H1 作为实用方法被否定，并记录原因。

**结果（2026-10-13，commit `473018a` 运行；只读校准集与验证集）**

| | JHQ 的 T_min（验证） | 校准选出的参数与验证集 T_min：LLR-iso / LLR-bias / LMP | 最小 T 处 recall 差（验证，相对 JHQ） | T ≥ ck/2 处 recall 差 |
|---|---:|---|---|---|
| arxiv（ck 1000） | 750 | λσ=3 → 960 / 2βσ²=16 → 1250 / κσ=1.5 → 960 | +0.0020 / +0.0035 / +0.0020（T=125） | 0 … +0.0015 |
| vogue（ck 640） | 640 | 1.0 → 640 / 8.0 → 1280 / 0.5 → 640 | +0.0020 / 0.0000 / +0.0015（T=80） | 0 … −0.0005 |
| openai3（ck 40） | 25 | 1.5 → 30 / 8.0 → 30 / 1.0 → 30 | −0.0005 / −0.0065 / 0.0000（T=10） | 0 |

**更多观察：**
- 各权重向量与 JHQ 线性权重的余弦为 0.94–0.9997。
- GT 近邻对随机负例的误排序率：
  - LLR-bias 在 arxiv 上降低最多，校准集上从 6.2e-4 降到 5.4e-4（−12%）；
  - 其余变体在 ±5% 之内；
  - LLR-bias 在小 β 时反而更差（例如 arxiv 2βσ²=0.5 时为 8.9e-4）。

**判定：H1 被否定。**
- 三个数据集的验证集 T_min 都没有减少，持平或变差。
- 固定 T 下的 recall 变化 ≤ 0.35 个百分点，只出现在最小预算上，在匹配 recall 的区间完全消失。
- 结果与 THEORY.md 3.4 的预言一致：纯重加权的 SNR 上限是 ×1.004–1.015。

**诊断：**
1. **数学等价：** 独立特征的 LLR 关于码仿射，与 JHQ 的差别只是线性泛函，权重方向又几乎相同，信息量不变。
2. **模型偏差无关紧要：** 换用偏置感知的背景模型，最多只是给近似常数的 bit 降权，降低一点噪声；零阈值丢掉的信息无法靠权重找回。
3. **T_min 判据的局限：** recall 曲线在目标附近非常平坦，验证集上 1 个近邻（0.0005）的差就能让 T_min 跳一档网格。所以第 1 轮的“变差”同样不显著，正确的读法是“没有可检测的改善”。

**下一步：** 第 2 轮按预注册改为修正编码阈值，即诊断 2 指向的根源。

## 第 2 轮：排序最优阈值（重新编码，单一全局阈值 / 每维）

**预注册（2026-10-13，第 1 轮结果前）**

- **假设 H2：** 真实 embedding 旋转后各维并不以 0 为中心（论文 Lemma 2 的 N(0, σ²) 假设不成立），零阈值因此不是排序最优的。
  - 在对称位置模型下，最小化 Bhattacharyya 误排序界的阈值就是每一维的分布中心（中位数），见 THEORY.md 5.2。
  - 按 t_j = 中位数重新编码（每侧取条件均值作重建值，残差按 JHQ 的方式重训），应减少所需的 T。
  - 收益应随实测的符号偏置排序：arxiv > vogue > openai3。
- **与 JHQ 的本质区别：**
  - 量化阈值和重建值按每一维的数据分布确定；JHQ 是全局零阈值加共享的 ±c。
  - 每向量 bit 数不变。
  - 全局元数据增加 3d 个 float（阈值和两个重建值）。
  - GPU 侧只改 LUT 表值，16+16 分解仍然成立。
- **对照：**
  - `lloydmax`：每维的重建最优 2 电平 Lloyd–Max。如果它与 `median` 一样好，收益就来自“去中心化偏置”本身，不是“排序最优”这个目标。
  - `mean`：以均值为阈值。
  - `jhq_re`：JHQ 的离线复现，用来确认整条管线与论文索引一致。
- **否定标准：**
  - (a) 在偏置最大的 arxiv 上，`median` 的验证集 T_min 减少不到 10%，则否定 H2；
  - (b) 若收益不按偏置大小排序（例如 openai3 与 arxiv 一样大），则否定“偏置是机制”这一解释。

## 第 3 轮：成对排序损失学习阈值（Candidate B）

**预注册（2026-10-13）**

写这一节时，已经看到第 2 轮在 arxiv 上的校准集和验证集结果（中心阈值大幅减少 T）；vogue 与 openai3 尚未出结果。

- **假设 H3：** 直接最小化成对 logistic 排序损失（brief 的 L_rank），可以找到比“排序最优模型解”（中位数）和“重建最优解”（Lloyd–Max）更好的 1-bit 编码准则：
  - `rl_t`：只学阈值，电平取条件均值；
  - `rl_tl`：阈值和两侧电平都学。
- **训练数据：** 只来自数据库，评估查询及其真值从不读取。
  - 2 万个库内向量作伪查询，用精确 kNN 取正例；
  - 负例为精确排名 11–110 的向量，以及按 IVF 路由（128 个最近 list）抽样的候选。
  - 另留 2000 个伪查询做训练内的检查。
- **起点：** 每个变体从 t = 0（JHQ）和 t = 中位数两处出发，用来看损失把阈值推向哪里。
- **与第 2 轮的区别：** 第 2 轮的阈值由模型推导（对称位置模型下的 Bhattacharyya 最优）。第 3 轮不假设分布，直接对真实近邻对优化，可以捕捉非对称边缘、坐标相关等模型外的结构。
- **成本：** 与第 2 轮相同：每向量 bit 不变，全局 3d 个 float。训练约几分钟 GPU。
- **否定标准：** 在验证集上，`rl_t` 和 `rl_tl` 的 T_min 在**所有**数据集上都没有比 `median` 低 ≥ 10%，则 H3 被否定。此时结论是：排序损失没有找到中心化以外的结构。
- **附加检验：**
  - 从 t = 0 出发的 `rl_t` 若收敛到中位数附近（|t − median|/σ 远小于 |median|/σ），则独立佐证了 THEORY.md 5.2；
  - 若没有收敛到中位数附近，说明对称模型不能描述真实数据。

**结果（commit `db6a809` 运行；只读校准集与验证集）**

| | median 的 T_min（校准 / 验证） | rl_t：zero / median 起点 | rl_tl：zero / median 起点 | rl_tl 在最小 T 处相对 median 的 recall 差（校准 / 验证） | rl_tl 在 T = ck 处的 recall 差 | rl_tl 的 primary MSE（median 0.109 / 0.280 / 0.334） |
|---|---|---|---|---|---|---|
| arxiv | 320 / 320 | 320, 320 / 960, 320 | 240, 480 / 320, 375 | +2.3 / +2.0 pp（T = 62） | −0.35 / −0.25 pp | 3.39 / 5.34 |
| vogue | — / — | 640, — / —, — | 800, — / —, — | +1.0 / +1.6 pp（T = 40） | +0.2 / −0.1 pp | 12.2 / 12.3 |
| openai3 | 30 / 30 | 40, — / —, 30 | — / — | −0.7 / −0.05 pp（T = 10） | −0.2 / −0.15 pp | 27.0 / 27.5 |

“—”表示在 4·ck 以内达不到目标 recall。

**训练内检查：** 从 t = 0 出发的 `rl_t` 收敛到中位数附近：|t − median|/σ 为 0.14（arxiv）和 0.13（vogue），而中位数本身离 0 有 1.27σ 和 0.50σ。独立佐证了 THEORY.md 5.2。

**判定：H3 被否定。** 验证集上，没有任何学到的变体在任何数据集上比 median 的 T_min 低 ≥ 10%。

**诊断：**
1. **阈值：** 排序损失把阈值推到中位数，与理论一致，因此 `rl_t` ≈ `median`。
2. **电平：** 让电平也参与学习（`rl_tl`），确实学到了更好的 primary 排序。arxiv 上随机负例的误排序率比 median 低约 37%，小预算的 recall 提高 2 pp。
   - 但学到的电平不再是条件均值，primary 重建 MSE 变大 30–80 倍，残差的 256 个电平要覆盖大得多的范围、精度下降，全 IVF recall（精排上限）降了 0.25–0.35 pp。
   - 排序损失只看 primary 打分，看不到它对层次重建的破坏。
3. **结构性冲突：** JHQ 的 primary 电平同时承担“排序打分”和“残差的参照点”两个角色，用同一组参数优化排序就会伤到重建。

**下一步：** 把两者解耦：编码和重建保持条件均值（残差不受影响），排序打分另用一个解码器，即第 4 轮。

## 第 2 轮结果与诊断（追加于第 3 轮运行期间；只读校准集与验证集）

| | 匹配 recall 所需 T（校准 / 验证）JHQ → median | 小预算处 recall 差（median − JHQ，校准 / 验证） | T = ck 处 recall 差 | 误排序率（随机负例）JHQ → median |
|---|---|---|---|---|
| arxiv（ck 1000） | 875 → **320** / 750 → **320** | +5.7 / +5.8 pp（T = 62）；+3.1 / +3.1 pp（T = 125） | +0.5 / +0.3 pp | 6.2e-4 → 2.9e-4 |
| vogue（ck 640） | 560 → 达不到 / 640 → 达不到 | +1.9 / +0.7 pp（T = 40）；+0.7 / +0.3 pp（T = 80） | −0.2 / −0.2 pp | 2.5e-4 → 2.1e-4 |
| openai3（ck 40） | 40 → 30 / 25 → 30 | −0.1 / −0.7 pp（T = 10） | +0.07 / +0.05 pp | 2.5e-5 → 3.5e-5（变差） |

**其他观察：**
- **复现核对：** 离线复现 `jhq_re` 与论文索引的差异在 ±0.1–0.2 pp 之内。vogue / openai3 上它在 T = ck 处略低于论文索引，按 T_min 判据甚至“达不到”。这就是残差码本重训本身的噪声带。
- **三种去中心阈值：** `lloydmax`、`mean`、`median` 的结果彼此接近，说明收益来自“去中心”本身，与选用重建最优还是排序最优的准则无关。
- **重建误差：** primary 与层次重建的 MSE 在 arxiv 上分别下降 71% 和 55%，vogue 上 26% 和 20%，openai3 上 12% 和 22%。

**判定：H2 未被否定。**
- 预注册标准 (a)：arxiv 的 T_min 减少 57–63%，远超 10%。
- 预注册标准 (b)：收益确实按偏置排序，arxiv ≫ vogue > openai3。

**但它不满足 brief 的离线 GO：**
- GO 要求至少两个数据集在原目标 recall 下减少 ≥ 25%，这里只有 arxiv。
- vogue 的收益集中在小预算；到达 JHQ 在 ck 处的 recall 平台（几乎就是全 IVF 上限）后，差异落在残差重训的噪声带内。

**诊断：**
1. 去中心修复的是 Lemma 2 的“零均值”假设，收益正比于各数据集的偏置。openai3 本来接近零均值，所以几乎没有可修的。
2. vogue 的 T_min 判据被平台和噪声主导，需要逐查询的配对统计（evaluator 已改为保存逐查询曲线，属事后补充分析，单独标注）。

## 第 4 轮：线性 MMSE（Bussgang）解码打分（Candidate C，研究者自提）

**预注册（2026-10-13，第 3 轮评估运行期间，第 3、4 轮的召回结果都尚未看到）**

**来源与推导更正：**
- 我最初的一阶推导认为，对去中心的高斯坐标，Cov(b) 与 Cov(y, b) 的相关结构在一阶上相同（arcsine 律），所以线性 MMSE 解码矩阵 B 接近对角，不比逐维解码好，打算在推导阶段就放弃。
- 廉价核实（`diag_lmmse.py`，只用数据库样本）推翻了这个推导：
  - B 的非对角能量占 21–72%；
  - 重建 MSE 降低 34–50%；
  - 库内向量对的内积估计 MSE 降低 56–87%（JHQ 码与 median 码都如此）。
- 推导的错误在于把“相关系数逐元素很小”当成“相关矩阵在谱意义上接近 I”。这些 embedding 的有效秩只有 d 的 7–9%（参与比 57–267），Cov(b) 的逆在低方差方向上会放大一阶以下的差异。

**假设 H4：** 在完全相同的码上，用线性 MMSE 解码器 ŷ(b) = μ + B(b − p) 给出的内积估计 ⟨q′, ŷ(b)⟩ = ⟨Bᵀq′, b⟩ + 常数来做 primary 排序，比 JHQ 的逐维权重排序更好。三个数据集都是单位向量，所以内积排序等价于 L2 排序。

**机制：**
- 1-bit 码可以看作对一个低维（有效维度 ≪ d）信号的 d 次 1-bit 测量。逐维解码相当于把每次测量独立地映射回去，量化噪声分布在全部 d 维。
- 线性 MMSE 在高斯先验下利用测量之间的相关，把噪声投到数据所在的子空间之外。

**与 JHQ 的本质区别：**
- 排序用的线性泛函从“查询本身”变成“查询经 Bᵀ 变换后”；
- B 是由码的二阶统计量决定的全局 d×d 矩阵，与查询无关；
- 码、bit 预算、16+16 查表结构都不变；查询端每批多一次 d×d 矩阵乘。

**成本：**
- 每向量 0 bit；全局多一个 d×d 浮点矩阵（768 维 2.4 MB，3072 维 38 MB）。
- 精排仍用原码的 D_H。打分值不再是 ‖q′ − ŷ‖²，所以 GPU 上精排需要用原表重算选中候选的 D_P，或直接计算 D_H。这是一处小的 kernel 改动。

**否定标准：**
- 在验证集上，`lmmse@JHQ` 与 `lmmse@median` 都没有在至少两个数据集上把 T_min 降低 ≥ 25%（brief 的离线 GO 门槛）；
- 或者固定 T 下的 recall 改善小于逐查询配对 95% CI 能分辨的幅度。
- 满足其一即否定 H4。

**新颖性预判（见 NOVELTY_AUDIT.md）：**
- 线性 MMSE / Bussgang 解码本身是经典工具（1-bit 压缩感知、1-bit MIMO 信道估计）；
- 二值码的线性解码器在哈希文献中也存在，例如 Binary Autoencoder 的线性解码器。
- 本轮能声称的至多是“把它用于 JHQ 的非对称 primary 筛选，并量化了有效维度带来的收益”，不是新工具。

**结果与诊断**：（实验后追加）
