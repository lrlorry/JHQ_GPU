## 结论

**总判定：NO-GO。** “排序最优的 1-bit 量化”不能形成新的 ANN 算法或独立论文。

**唯一被测试集确认的收益是第 2 轮的每维中位数阈值（`median`）。** 它属于已有做法，只在 arxiv 上有效：
- 测试集上，匹配 JHQ recall 所需的精排候选从 875 降到 375（−57%）；
- T = 250 处 recall +1.50 pp，95% CI [+1.05, +2.00]；
- 由实测阶段时间推导的端到端节省为 b = 8 时 22%、b = 1000 时 12%（[推导]，未上 GPU）。

**另两个数据集：**
- vogue：小预算处测试集显著改善（T = 80 时 +1.3 pp），但 recall 平台低 0.1 pp（不显著），按严格目标“达不到”；
- openai3：没有可分辨的差别。

brief 的离线 GO 要求至少两个数据集候选减少 ≥ 25%，这里不满足，所以**没有做 GPU 原型**。v67 的导入与对比基准只编译通过，没有运行。

**其余四个候选都被预注册标准否定：**

| 轮次 | 候选 | 否定原因 |
|---|---|---|
| 1 | 近邻似然比（LLR）打分 | 理论上只是重加权，模型内 SNR 上限 ×1.015；实测无改善 |
| 3 | 成对排序损失学阈值与电平 | 阈值收敛回中位数；学电平会破坏残差重建 |
| 4 | 线性 MMSE（Bussgang）解码打分 | 估计 MSE 降低 56–87%，近邻排序却大幅变差 |
| 5 | 按 IVF list 的中心阈值 | 重建 MSE 降低 33–46%，list 内排序变差；元数据摊到每维 0.35–0.79 bit |

**贯穿五轮的发现：** primary 的“估计好不好”和“局部近邻排序好不好”是两个不同的目标。
- 第 3、4、5 轮都在这一点上失败：重建或内积的均方误差变小，近邻排序反而变差，或者相反。
- 第 5 轮的诊断还发现：JHQ 式的 D_P = ‖q′ − ŷ‖² 在中点不为 0 的码上隐含了一次“查询居中”。这是第 2 轮收益的一部分来源，也是按 list 编码在 list 内失败的原因之一。

## A. 研究问题

**JHQ 的量化目标是什么？** [源码]
- 对 JL 旋转后的坐标 y = Πx，JHQ 假设各维独立服从 N(0, σ²)（论文 Lemma 2），按这个分布做 1-bit Lloyd–Max 量化：
  - 阈值为 0，即 b_j = 1[y_j > 0]；
  - 所有维共用电平 ±0.6745σ，σ = 1/√d；
  - 残差相对 primary 重建做 8-bit 标量量化。
- 这是**重建均方误差**意义下的最优，前提是 Lemma 2 成立。

**它对 ANN 排序是否最优？** 分两层：

1. **在 Lemma 2 的模型 M0 内** [证明]：
   - JHQ 的 primary 排序等价于“给定码的条件期望距离”（距离的 MMSE 估计）的排序（THEORY.md 2.2）；
   - 按概率排序原则，这不等于 Top-k recall 最优，因为后验方差依赖符号一致的模式（2.3）；
   - 但改进空间极小：任何纯重加权的排序信噪比上限只有 ×1.004–1.015（3.4）。
2. **在真实数据上** [实测]，Lemma 2 的“零均值”在 arxiv 上严重失效：
   - 均值向量范数 0.84，各维 |μ_j|/σ_j 平均 1.22；
   - JHQ 的 bit 平均只有 0.56 bit 熵，10% 的 bit 有 98.7% 以上的时间取同一个值；
   - vogue 与 openai3 的偏离小得多（熵 0.885 / 0.963）。
   - 零阈值在这种情况下既不是重建最优，也不是排序最优（5.2）。

本研究要回答的问题是：在**完全相同的 bit 预算**（每维 1 bit 主码 + 8 bit 残差 + 每向量一个 float，不加每向量 FP32 附加量）下，能否找到比 JHQ 更好的 primary 排序，使匹配 recall 所需的精排候选数 T 显著减少。

## B. 理论分析

### B.1 得到证明的性质

| 结论 | 位置 | 性质 |
|---|---|---|
| E[X \| s] = σ√(2/π)·s；JHQ 用的电平 0.6745σ 是 \|X\| 的中位数而不是条件均值，但不影响 primary 排序 | THEORY.md 2.1–2.2 | 证明 |
| JHQ 的 primary 排序 = M0 下距离 MMSE 估计的排序；c 的取值不影响排序 | 2.2 | 证明 |
| MMSE 排序不一定 Top-k 最优（后验方差依赖一致模式；u = ±σ 时方差 0.27σ⁴ 与 6.64σ⁴） | 2.3 | 证明 + 数值 |
| 独立 bit 的任何似然比关于 s 仿射，LLR 打分只是换一组线性权重 | 3.2、3.4 | 证明 |
| LLR 权重的小 β / 大 β 极限（线性 / 平方加权） | 3.3 | 证明 + 数值 |
| 纯重加权的 SNR 上限：Cauchy–Schwarz 最优权重 h* = g/v | 3.4 | 证明 |
| 配对误排序的 Bhattacharyya 界 Π_j ρ_j²，t = ½ 最优；非 LLR 打分的 Chernoff 界 | 4.1–4.2 | 证明（经典技术的配对版本，不是新定理） |
| 配对误排序率不是 Top-k recall 保证 | 4.4 | 证明 |
| 对称位置模型下，误排序界最优的阈值是分布中心 | 5.2 | 证明 + 数值 |
| 阈值偏离中心 a 个标准差时，bit 的 Fisher 信息比为 φ(a)²/(Φ(a)Φ(−a))：a = 1 时 0.689 | 5.3 | 证明 + 数值 |
| 1-bit 码的线性 MMSE 解码 B ≈ √(π/2)σR(R + 0.571I)⁻¹，即对白色符号噪声的 Wiener 滤波 | 7.3 | 证明 |
| D_P = 常数 − 2Σ_j (q′_j − c_j)D_j s_j：中点不为 0 时，D_P 隐含对查询的居中 | 5.5 更正 | 证明 |

### B.2 依赖理想高斯 / 独立模型的结论

- 2.2 的 MMSE 等价、2.3 的方差公式，依赖 M0：各维独立、对称、两侧条件方差相同。
- 3.4 的 SNR 上限，在独立高斯近邻模型内计算。
- 4.1–4.2 的误排序界依赖坐标独立。
- 5.2 依赖对称位置模型；5.3 依赖高斯边缘分布。
- 7.3 的闭式依赖零阈值高斯；线性 MMSE 估计本身不依赖。

### B.3 不适用于真实 Top-k 的结论 [实测]

1. **误排序界在真实数据上不成立**（THEORY.md 4.5）。
   - 独立模型下的 Bhattacharyya 界和 Chernoff 界比经验误排序率低 2 到 50 个数量级，在 76–100% 的查询上低于经验值。
   - 原因是坐标高度相关：有效秩只有 57 / 66 / 267。
   - 把指数里的 d 换成有效秩，只能对上 openai3。
   - 唯一成立的 Cantelli 界（0.05–0.10）又松了 2–3 个数量级。
   - 这些界只能给方向性结论，不能给定量保证。
2. **配对误排序率与 recall 不能互相替代。** 第 3 轮的 `rl_tl` 把随机负例误排序率降低 37%，全 IVF recall 却下降。
3. **MSE 最优不等于近邻排序最优**（7.6）。
   - 全局 LMMSE 解码在“所有向量对的平均”上最优；
   - 但 IVF 探查的候选是局部子集，局部排序依赖的方向正是被全局收缩压掉的方向。
4. **“中心阈值排序最优”只对单一背景分布成立。** 一次查询的候选来自 128 个 list；按 list 居中后，list 内与跨 list 的比较需要不同的居中（第 5 轮诊断）。理论没有覆盖这种混合背景。

## C. 算法设计

**统一记号：**
- b_j = 1[y_j > t_j]，s_j = 2b_j − 1；
- 两侧电平 lo_j、hi_j，中点 c_j = (lo_j + hi_j)/2，半宽 D_j = (hi_j − lo_j)/2；
- primary 距离 D_P = ‖q′ − ŷ‖²，ŷ_j = c_j + D_j s_j。

**所有改编码的变体：**
- 都用 JHQ 的流程重训残差：同一组 10 万训练向量、每子空间 256 电平 1-D Lloyd，并重算 corr；
- 精排都用各自的 D_H = ‖q′ − ŷ − r̂‖²；
- 每向量 bit 数严格等于 JHQ：d + 8d bit + 32 bit。

| 轮次 | 方法 | 编码 | 打分（primary） | 与 JHQ 的区别 | 额外元数据 | 查询端额外工作 |
|---|---|---|---|---|---|---|
| 1 | LLR-iso / LLR-bias / LMP | 不变（JHQ 的码） | Σ_j w_j s_j，w_j = ½ψ(λq′_j)（LLR-bias 另有背景项；LMP 为局部最优权重） | 只换线性权重 | 0（LLR-bias 2d 个 float） | 每维一次非线性函数 |
| 2 | median / mean / lloydmax | t_j = 每维中位数（均值 / Lloyd–Max）；lo、hi 为两侧条件均值 | D_P | 阈值与电平按维由数据决定 | 3d 个 float | LUT 表值换成按维的两电平，16+16 分解不变 |
| 3 | rl_t / rl_tl | 阈值（rl_tl 还有电平）由成对 logistic 排序损失在库内伪查询上学出 | D_P | 由排序损失直接优化 | 3d 个 float | 同第 2 轮 |
| 4 | lmmse@JHQ / lmmse@median | 不变（JHQ 或 median 的码） | ⟨Bᵀq′, b⟩，B = Cov(y, b)(Cov(b) + rI)⁻¹，由库样本估计 | 排序用的线性泛函经 Bᵀ 变换 | d² 个 float | 每批一次 d×d 矩阵乘；精排需重算 D_P |
| 5 | list_median / list_mean | 每个 IVF list 每维一个阈值（list 内中位数 / 均值），电平为 list 内条件均值 | D_P（按 list 的电平） | 相对 list 中心编码（IVFADC / RaBitQ 式），但不存每向量校正量 | 3·d·nlist 个 float：75.6 / 37.8 / 302 MB，摊到每维 0.35 / 0.42 / 0.79 bit | 每个（查询，list）一张表 |

**理论性质：**

| 轮次 | 性质 |
|---|---|
| 1 | 只是重加权；在独立模型下，LLR 在所有关于 s 的仿射打分中误排序指数最优 |
| 2 | 在对称位置模型下，按 Bhattacharyya 指数排序最优（5.2）；在单峰对称边缘下与 Lloyd–Max 重合（5.4） |
| 3 | 无闭式性质 |
| 4 | 在仿射估计量中，重建误差与任意固定查询的内积误差都最小（7.1） |
| 5 | 对单个 list 内的比较，继承第 2 轮的性质 |

**计算成本：**
- 第 1、2、3 轮：扫描结构与 JHQ 完全相同；
- 第 4 轮：需要一次 kernel 改动；
- 第 5 轮：需要按（查询，list）建表。COST_MODEL.md 推导表明，仅建表成本就足以抵消它在 arxiv 上的候选减少。

## D. 实验结果

### D.1 指标与读法

**主要指标：**
- recall@10 对精排预算 T 的曲线：primary top-T 用各自的 D_H 精排；
- **T_min**：recall 达到“JHQ 在 T = ck 处 recall”的最小网格 T，即 brief 的“保持 v65 目标 recall 所需的候选数”；
- 逐查询配对差：按查询重采样 bootstrap，95% CI；
- 配对误排序率：GT top-10 对随机负例 / 近边界负例；
- GT 近邻在 primary 中的排名；
- 全 IVF recall：全部候选都用 D_H 精排，即 Full-IVF Reconstructed Distance Oracle。

**与 brief 指标的一处偏差：** primary 排名分布统计的是 ground-truth top-10 的排名，不是“全 IVF D_H 的 top-10”的排名。recall 本身就是对 ground truth 算的，所以这样更直接。

**T_min 的局限：** recall 曲线在目标附近非常平坦，验证集上少 1 个近邻（0.05 pp）就能让 T_min 跳一档网格。因此每轮都补了配对 CI，事后补充的读法另有标注。

**噪声参照：** JHQ 的离线复现 `jhq_re`（同一方法，只是残差码本由离线流程重训）在 arxiv 验证集上的 T_min 是 625，而论文索引是 750。单个数据集上 ±1 档网格的 T_min 差别不算收益。

### D.3 排序误差、primary 排名与全 IVF 上限（验证集）

| 方法 | 误排序率（随机负例）arxiv / vogue / openai3 | GT top-10 中最差的 primary 排名（查询平均） | 全 IVF recall |
|---|---|---|---|
| JHQ | 5.6e-4 / 2.5e-4 / 3.8e-5 | 140 / 62 / 11.3 | 0.9805 / 0.9574 / 0.9025 |
| median | 2.5e-4 / 2.5e-4 / 4.8e-5 | 71 / 65 / 11.5 | 0.9820 / 0.9564 / 0.9029 |
| rl_tl（zero 起点） | 1.6e-4 / 2.3e-4 / 4.1e-5 | 48 / 53 / 11.9 | 0.9795 / 0.9545 / 0.9019 |
| lmmse@JHQ | 1.8e-3 / 2.1e-3 / 6.7e-5 | 470 / 613 / 13.4 | 与 JHQ 相同（精排用原 D_H） |
| list_median | 3.3e-4 / 3.8e-4 / 2.4e-4 | 89 / 81 / 29.4 | 0.9830 / 0.9590 / 0.9015 |

**怎么读：**
- **arxiv：** median 把 GT 近邻的最差 primary 排名从 140 提到 71，误排序率减半；全 IVF 上限也高 0.15 pp，因为 primary 重建更好，残差更细。
- **第 3 轮的 rl_tl** 排名最好（48），但全 IVF 上限最低：学到的电平破坏了残差重建。
- **重建误差：** median 的 primary / 层次重建 MSE 相对 JHQ 下降 71% / 55%（arxiv）、26% / 20%（vogue）、12% / 22%（openai3）。
- **primary 单独的作用：** 用 median 的 primary 排序、JHQ 自己的 D_H 精排，arxiv 验证集 T_min 为 480，即 primary 单独贡献 −36%（校准集 875 → 480 为 −45%）。其余来自更精确的 D_H。

**误排序界与经验值的对照**见 THEORY.md 4.5 与 `RANK_ERROR_ANALYSIS.csv`：独立模型的界失效，Cantelli 界成立但太松。

| vogue | 640 | 2.2% / 3.2% / 94.5% | 少 1 个 |
| openai3 | 10 | 23.8% / 21.8% / 54.5% | 少 2 个 |
| openai3 | 40 | 0.8% / 1.8% / 97.5% | 少 1 个 |

没有单条查询出现大幅退化：最坏的情况是在 vogue 的最小预算处少 3 个近邻。

### D.6 可信度

**可信的结论：**
- arxiv 的收益：校准、验证、测试三个独立划分方向一致，幅度相近（T_min −63% / −57% / −57%），CI 远离 0；
- 有清楚的机制（Lemma 2 的零均值失效，见 A），收益按偏置大小排序；
- 第 1、4、5 轮的否定：CI 宽度远小于效应。

**不确定的地方：**
- vogue 的平台差 −0.1 到 −0.2 pp，在残差重训的噪声带内（CLAUDE.md：两次构建之间 1e-3 以下的 recall 差别没有意义）；
- 端到端时间是推导值。

## E. 失败与改进过程

**第 1 轮：近邻似然比打分（H1 否定）。**
- **为什么失败：** 独立 bit 的似然比关于码仿射，只能换一组线性权重。最优权重与 JHQ 的权重余弦为 0.957–0.996，SNR 上限 ×1.015。码里没有的信息，打分找不回来。
- **指向的问题：** 信息在编码时已经丢了，零阈值在偏置维上产生几乎恒定的 bit。

**第 2 轮：排序最优阈值，即每维中心（H2 未否定，但只在 arxiv 达到 GO 幅度）。**
- **解决的数学问题：** Lemma 2 的零均值假设失效时，误排序界最优的阈值是分布中心（5.2）。
- **结果：** 收益按偏置排序，arxiv ≫ vogue > openai3，与 Fisher 信息的预言（57% / 93% / 98% 信息保留）一致。
- **对照组：** mean、lloydmax 与 median 几乎相同，说明收益来自“去中心”本身，而不是“排序最优”这个特定准则。
- **局限：** vogue、openai3 本来就接近零均值，没有可修的。

**第 3 轮：直接最小化排序损失（H3 否定）。**
- **想解决的问题：** 第 2 轮的阈值由模型推出，排序损失可能找到模型之外的结构。
- **结果：**
  - 只学阈值时，从 0 出发收敛到中位数附近（|t − median| 为 0.13–0.14σ，而中位数本身离 0 有 0.5–1.27σ），独立佐证了 5.2；
  - 连电平一起学时，primary 排序更好，但重建 MSE 变大 30–80 倍，全 IVF recall 下降。
- **被证伪的假设：** “排序损失能找到中心化以外的结构”。暴露的结构问题是：JHQ 的 primary 电平同时承担“排序打分”和“残差参照点”两个角色。

**第 4 轮：把打分与重建解耦，线性 MMSE 解码（H4 否定）。**
- **想解决的问题：** 码与重建保持不变，只用 Bussgang / Wiener 解码改进排序用的内积估计。
- **我的推导错误：** 预注册时我推导“B 接近对角、无收益”，漏掉了 arcsine 律的对角项 π/2 − 1。廉价核实推翻了它，THEORY.md 7.3 已更正。
- **结果：** 内积估计 MSE 降低 56–87%，近邻排序却大幅变差（arxiv T = 125 处 −10 pp）。损失按有效秩排序（vogue > arxiv > openai3）。
- **被证伪的假设：** “估计更准 ⇒ 排序更好”。全局 MSE 最优的收缩压掉的，正是区分局部近邻的方向（7.6）。

**第 5 轮：把编码局部化到 IVF list（H5 否定）。**
- **想解决的问题：** 第 4 轮说明排序发生在局部；list 内的符号偏置（0.43–0.73）大于全局偏置。
- **结果：** 重建 MSE 降低 33–46%，全 IVF 上限持平或略升，但 primary 排序变差：小预算处 openai3 −12.7 pp，vogue −1.3 pp。vogue 上 T_min 的 −25% 只是平台效应。
- **诊断一（`diag_list.py`）：** 我预想的“跨 list 偏差”被否定。list 间误差方差反而下降 73–86%；损失在 list 内部，同 list 误排序率是 median 的 1.6–3.9 倍。
- **诊断二（`diag_norm.py`）：** 我预想的“‖ŷ‖² 是噪声”也被否定。
  - D_P = 常数 − 2Σ_j (q′_j − c_j)D_j s_j，即 D_P 用居中后的查询给 bit 加权；
  - 对全局 median 码，这一居中去掉了均值方向上的粗估计，是第 2 轮收益的一部分（去掉居中后，arxiv 在 T = 125 处 −14 pp）；
  - 对按 list 的码，居中去掉了“离 list 中心多近”这个在 list 内有用的量。
  - openai3 上还有一个跨 list 的损失（误排序率约为 median 的 7 倍），机制没有查明。

**两条最终被证伪的设计直觉：**
1. 更好的重建，或更好的平均估计，会带来更好的近邻排序。第 3、4、5 轮三次反例。
2. 按 IVF list 局部化编码会更好。在不存每向量校正量的预算下不成立：RaBitQ 式的局部编码依赖每向量的范数和内积校正量。

**停止原因：** 五轮已经用完（brief 的上限）。第 5 轮的诊断给出了线索（见 G），但没有作为第 6 轮继续。

## F. 新颖性判断

以顶会审稿标准逐项判断：

| 候选 | 判断 | 理由 |
|---|---|---|
| 第 1 轮 LLR 打分 | 已有方法的简单变体 | 等价于对符号内积做奇函数重加权；同类估计量见 P. Li（AAAI 2019）。没有带来改进 |
| 第 2 轮 中位数阈值（median） | **已有做法 / 工程修正** | 中位数或均值阈值、零中心化是哈希的标准步骤（ITQ、Self-Taught Hashing、cuVS binary quantizer）。本研究的贡献只是分析：量化了 JHQ 的 Lemma 2 在真实 embedding 上失效的代价，并指出 D_P 的隐含居中 |
| 第 3 轮 排序损失量化 | 已有方法的简单变体 | 属于用排序损失学二值码（MLH、HDML 等）；结果退化为中位数阈值 |
| 第 4 轮 Bussgang LMMSE 打分 | 已有工具的应用（负结果） | 估计量与 1-bit MIMO 的 BLMMSE（Li 等，TSP 2017）相同 |
| 第 5 轮 IVF 条件阈值 | 已有做法（负结果） | IVFADC / RaBitQ 的相对质心编码，去掉了它们的每向量校正量 |

**对 brief 五个问题的回答：**
- **只是 Engineering Optimization 吗？** median 阈值是，而且只对强偏置数据有效。
- **已有方法的简单变体吗？** 第 1、3 轮是。
- **有效的新统计估计器吗？** 没有。第 4 轮的估计器是已有的，而且在排序上无效。
- **有理论价值的新量化方法吗？** 没有。
- **能否形成独立 ANN 论文？** 不能。可以在 JHQ-GPU 的论文或技术报告中，作为“数据相关的阈值居中”写一段消融。必须注明它是已有做法，只在偏置大的数据集（bit 熵低）上有效。

详细文献对照见 NOVELTY_AUDIT.md。所有检索结论只核实到题目、出处与核心思想，不宣称任何“首创”。

## G. 最终结论

### 判定：NO-GO

- **研究方向：** 在相同 bit 预算下，五轮没有找到在两个以上数据集上显著改善 Recall–T 前沿的 1-bit 量化或打分方法。离线 GO 不成立，不进入 GPU 实现。
- **工程上：** median 阈值是一个低成本、已有的修正，只对 arxiv 这类强偏置数据有效。

### 最有价值的发现

1. **JHQ 的 Lemma 2 在真实 embedding 上会严重失效，诊断很便宜。**
   - 零阈值 bit 的平均熵是一个简单指标：arxiv 0.56、vogue 0.885、openai3 0.963；
   - 它预言了第 2 轮的收益顺序；
   - 熵低的数据上，每维中心阈值能把匹配 recall 所需的候选减半以上（arxiv 测试集 −57%）。
2. **primary 的估计质量与近邻排序质量是两个目标**，三轮的反例都指向这一点：
   - 第 3 轮：排序更好，重建更差；
   - 第 4 轮：估计 MSE −56–87%，排序大幅变差；
   - 第 5 轮：重建 MSE −33–46%，list 内排序变差。
   - 以重建 MSE 为目标的设计（包括 JHQ 本身的 Lloyd–Max 电平）不能直接推出排序性质。
3. **D_P 隐含的查询居中。** 码本中点不为 0 时，D_P = ‖q′ − ŷ‖² 等价于用 q′ − c 给 bit 加权。这在 median 码上是必要的（去掉它，arxiv 在 T = 125 处 −14 pp），在按 list 的码上又是有害的。哪一种居中对局部排序正确，是一个具体的问题。
4. **误排序界的独立化假设在真实数据上完全失效**（差 2–50 个数量级），实际有用的只有方向性结论。

### 尚未解决的理论问题

1. **混合背景下的最优居中与阈值。** 候选来自 128 个 list，什么样的居中能同时保留 list 内的径向信息和跨 list 的可比性？理论上是否存在只依赖全局与 list 级统计量（不存每向量校正量）的最优打分？
2. **相关坐标下的误排序界。** 能否给出依赖有效秩或谱的、在真实数据上成立且不太松的界？简单的“d → 参与比”替换只在 openai3 上成立。
3. **openai3 上按 list 编码的跨 list 损失。** 在两种键下都约是 median 的 7 倍，机制未查明。可能与每个 list 只有约 122 个成员、却要估 3 × 3072 个参数有关，未验证。
4. **局部协方差的线性解码。** 7.6 指出，排序最优的线性解码应基于候选集的局部协方差，而不是全局协方差。它能否在不加每向量 bit 的前提下实现，没有研究。

### 真实收益

| 数据集 | 测试集确认的收益 | 推导的端到端节省 |
|---|---|---|
| arxiv | 匹配 recall 所需候选 −57% | b = 8 时 −22%，b = 1000 时 −12% |
| vogue | 只在小预算处 +0.6–1.3 pp，平台不变 | — |
| openai3 | 无 | — |

推导值未经 GPU 测量。

### 下一步

1. **若要把 median 阈值用进 JHQ-GPU（工程，不是研究）：**
   - 运行已编译的 `demo_jhq_v67_repr_bench`（约 20 分钟 GPU），在 b = 8 / 32 / 256 / 1000 下与 α 重调的 v65 对比；
   - 用零阈值 bit 熵作为是否启用的判据（例如熵 < 0.8）；
   - 注意重新编码需要重训残差码本。
2. **若继续研究：** 第一个方向是上面的问题 1，即混合背景下的居中。
   - 第 5 轮诊断已经给出可检验的形式：在 D_P 键与 IP 键之间，按方向选择性地居中。
   - 但它要先回答“不加每向量信息时能否成立”。从第 4、5 轮的经验看，先验概率不高。
3. **不建议继续：** LLR 式重加权（理论上限 1.5%）、全局 MSE 准则的解码、不带校正量的按 list 编码。
